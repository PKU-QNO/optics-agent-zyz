# mie-f OCR / 扫描件可信度说明

本文件说明 `papers/mie-f` 中各份 PDF 与其对应 OCR/Markdown 基线的当前可信度，供后续复用时快速判断：

- 这里讨论的是“PDF -> OCR/Markdown 转写可信度”，不是论文物理内容是否正确。
- 可信度结论基于 `papers/mie-f/_pdf_review/` 下现有审查报告，时间点为 `2026-07-26`。
- 如果后续重新 OCR、补扫描、或新增人工修订，本文件应同步更新。

## 可信度等级

- `A`：可直接作为工作基线使用。已有逐页核对，未发现实质性公式/文本问题。
- `B`：大部分可用，但带有已知局部问题。普通检索、阅读、粗引用通常可接受；关键公式前应看报告。
- `C`：只能作为参考基线。关键公式、表格、定义式使用前必须人工复核。
- `D`：当前不能视为可靠 OCR 基线。最多只可作视觉参考或临时辅助。
