\section{独立路径与错误注入}

\subsection{远场投影}

\texttt{far\_field\_projection} 不调用 Path B 的体积分角函数，而是独立构造 scipy \texttt{sph\_harm\_y} VSH、显式 outgoing Hankel $h_l^{(1)}=j_l+i y_l$，在包围球面执行 Grahn Eq.(3)(4) 的角向投影。样本半径为 $r/a=2$ 的验收调用，最大复相对误差为 $7.7439334\times10^{-15}$；该结果作为相位和通道标签的独立互证，不替代 Path B gate。

\subsection{解析 bump 与直接导数交叉}

解析 fixture 使用全空间 $C^2$ 多项式 bump，给出均匀极化球、双斑、环流和三个磁四极 $m$ 案例。对于已注册 bump，Eq.(13)(14) 的 raw 直接导数和 Eq.(15)(16) clean kernel 在 16 个 $(branch,l,m)$ 上逐项比较；最大误差 $1.6201542\times10^{-14}$。真实 Mie 球的直接导数接口 fail-closed，避免把边界分布项误当作普通有限差分。

\subsection{miepython 交叉}

在 $x_{\rm mie}=0.5$、$m=2.5$，独立库给出 $q_{\rm sca}=0.07842660729283048$，baseline 为 $0.07842660729283035$，相对误差 $1.5925729\times10^{-15}$，状态 PASS；缺少依赖时实现返回 BLOCKED，不以 pytest skip 伪装 gate 通过。
