  \item \textbf{Fig.1 指标口径：}论文 moment gate 与散射分项 $C$ 诊断不同。复矩口径的 exact 单点 ED/MD 已通过强审，但重开的条款没有新人工 receipt，不能自动晋级。
  \item \textbf{Fig.2 dielectric MQ：}RMSE/p95=0.02556/0.05695 超出 0.02/0.05。graphical floor 支持“与论文绘图下限一致”，但 strict fidelity 与 paper fidelity 仍 \rc{UNRESOLVED}。
  \item \textbf{Fig.2 材料域：}Johnson--Christy 在当前 Fig.2 网格仅支持到 1935 nm；$x_{\rm A}<0.258398$ 的缺口不外推、不拼接，所以完整金球面板为 \rc{MATERIAL\_DOMAIN\_LIMITED}。
  \item \textbf{Grahn Path A：}EQ 逐通道 1.385\% 是 rank-4 截断诊断；Path A 与 Table 1 同阶，不是独立 exact truth。
  \item \textbf{Grahn gate 4：}机器证据齐全不等于用户已经接受 mask、notes 与 \rc{method\_consistency} ceiling。
  \item \textbf{Fig.3 目标：}旧“Fig.3 Fano”名称不准确；Fano/方向性只作为 diagnostic，不是论文双盘四通道的主验收。
  \item \textbf{Fig.3 COMSOL：}频域 FEM 真解谱已得（9 点 $x=0.26$--$0.42$ + $x=0.36$ 网格收敛 + 远场/功率闭合），但 MD/EQ 网格残差 $\sim2\%$（Richardson $p\approx1.3$）、高阶 $l>4$ 未逐阶；BEM 128G 替代路径跑通且远场闭合良好，但 PEC 近似丢失金的 MD/EQ 磁共振（须 IBC 加损耗）。
  \item \textbf{Fig.3 来源与模型：}host、spacer、JC 1937--2000 nm 路线、panel-(b) metric/UQ 等仍有人工 gate；arXiv-v2 Eq.(1) 是当前 implementation authority，journal-final glyph 状态仍未决。

  \item \textbf{独立 exact match：}当前文献检索未发现与耦合双金盘、几何、材料、observable 和归一化全部匹配的独立闭式/公开数值真值；这不等于全领域不存在。
\end{enumerate}

\subsection{限制不是失败隐藏}

这些限制并不否定已有方法结果：Table 2--Mie 的球体验证、Grahn 的双路径和逐 $m$ 映射、金数据用途分层、Fig.3 的可复算代理与方向诊断均是有效产物。限制的作用是阻止“方法正确”“工程链可运行”“论文曲线接近”和“真实非球形结构已复现”之间的偷换。
