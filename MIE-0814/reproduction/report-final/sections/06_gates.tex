\subsection{必须使用的最新版本语义}

\begin{enumerate}
  \item Fig.1 的 169.7\%/167.7\%/2275\%/2453\% 已作废；采用 B1 exact 值。B1 的 interpolation 文本与脚本行为不一致，最终 gate 只用 direct exact。
  \item Fig.2 的“0.23026 大 gap 导致 MQ 削峰”已被 Opus \#08 推翻；该 gap 位于断段，MQ 根因必须保持 \rc{UNRESOLVED}。
  \item Fig.2 的 legacy point-estimate/vector 结果与 B3 最新 fail-closed UQ 是不同 gate。前者的逐通道结果继续披露；后者因 calibrated uncertainty、coverage 和 dense-mode 阈值不完备，将八条正式 lane 全部保持 \rc{UNRESOLVED}，不得继承 legacy PASS。
  \item Grahn \#14 的 BLOCKED 被 \#14b PASS 和后续当前快照复验覆盖；但这只覆盖 D1 实现缺口，不替用户签发 gate 4。
  \item Fig.3 spec 顶部的 \rc{APPROVED\_AS\_PATH\_CANDIDATE} 只表示主 agent 采纳 B12 路径设计；正文仍是 \rc{draft\_pending\_human\_approval}，正式执行与晋升须完成 FIG3-G0--G6。
  \item B9s mode-analysis 研究产物已经存在，但不等于已配置/已求解的 Fig.3 frequency-domain scattering template。
\end{enumerate}

\subsection{Result class 合同演进}

旧路线图列出七级 SEPR class，但后续 Grahn spec 采用项目局部的 \rc{method\_consistency}。本报告保留这一名称并明确其 ceiling，不静默归一化为 pipeline completed，也不包装为 physical reproduction success。Fig.1 则相反：\rc{PASS\_WITH\_LIMITATIONS} 与 \rc{metric\_decision\_pending} 是 gate/治理标签，不应虚构成一个已签发的七级 class。
