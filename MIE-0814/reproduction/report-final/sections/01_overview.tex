\subsection{证据层级与本报告重算}

最终数字采用以下优先级：冻结的 \texttt{data/*.csv|json} 与当前函数只读重算 $>$ 最新机器 gate/不可变收据 $>$ 当前 formalization spec $>$ 轮次报告 $>$ \texttt{WORK\_LOG.md}。本报告另建 61 项数字台账，逐项记录定义、来源字段和重算方式；对于 gate 与声称边界，另建审查台账并检查全部可用的 Opus RESULT。

需要特别区分三类误差：
\begin{enumerate}
  \item Table 2--Mie 是同一球场、同一材料下的\textbf{方法合同}；
  \item 论文 PDF-vector 与本地曲线比较是\textbf{图形/论文保真}；
  \item 论文 line 与 marker 自身的差异是\textbf{graphical floor}，只能解释可辨识下限，不能覆盖预注册 strict gate。
\end{enumerate}

\subsection{全局结论}

四轮共同建立了一条从局域散射电流 $\mathbf J(\mathbf r)$ 到 Cartesian 多极矩、球多极系数和可观测散射量的可审计链。该链在球体上的 Mie 真值和 Grahn 双路径映射上得到强数值支持；耦合金纳米盘由 COMSOL 频域 FEM 求得真解谱（9 点 + $x=0.36$ 网格收敛），并额外验证了 BEM 边界元方法（128G 对比 FEM 900G 内存）作为更省内存的替代求解器。因此，本项目最强的整体表述是“\textbf{方法链已被多重验证，论文物理保真按轮次分级，Fig.3 达到 partial physical match（COMSOL 真解谱）但 MD/EQ 网格残差与高阶多极待补}”，而不是“四图全部 unrestricted physical success”。
