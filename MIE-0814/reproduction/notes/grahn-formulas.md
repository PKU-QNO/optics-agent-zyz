## 2. 张量分解（M^(2) 四对象，审查 🔴1 修订）

M^(2)_αβ = i/ω ∫ J_α r_β d³r（9 分量、**一般不对称**）：

```
M2_raw[αβ]        = i/ω ∫ J_α r_β d³r            （9 分量原始矩）
M2_sym_traceless  = ½(M2+M2ᵀ) − ⅓I·tr M2         （对称无迹，5 维 → Q^e 相关）
M2_antisym        = ½(M2−M2ᵀ)                     （反对称，3 维对偶 → m 磁偶极）
M2_trace          = ⅓I·tr M2                       （1 维 → 暗模式）
```

- Q^e = 6·STF(M2_raw)，**仅长波（无 Bessel 核）成立**（审查 🔴2）。Alaee Table 2 的 Q^e 含 j₁(kr)/(kr)、j₃(kr)/(kr)³，有限 kr 下不等同。
- 磁偶极对偶：m_γ = ½∫(r×J)_γ d³r = (iω/2)ε_γαβ M2_αβ（讲义 §8 L99-110 已验 ✓）
- 反对称组合 Q_αβ−Q_βα 是磁偶极的来源（R2 反例：错喂对称 Q^e → 磁偶极消失）
