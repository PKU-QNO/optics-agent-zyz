## 一、我们用了什么：频域 FEM（有限元方法）

### 1.1 方法定位（对照用户方法库）

项目 COMSOL 求解用 `ElectromagneticWavesFrequencyDomain`（`ewfd`）——**有限元方法 + 频域**。

对照 `optics_agent/notes/plasmonics/chapter3.txt` 的方法库：

| 方法库条目 | 我们是否用 | 说明 |
|---|---|---|
| FDTD（时域有限差分） | ❌ | 时域显式推进，我们要的是稳态单频截面 |
| **FEM（有限元方法）** | ✅ | 频域，`ewfd` |
| DDA/CDA（偶极近似） | ❌ | 未用（见 §3 反思） |
| GFM/TMM（格林/转移矩阵） | ❌ | 未用 |
| MMS/PWE（多重散射/平面波展开） | ❌ | 未用 |
| **Mie 解析解（球体）** | ✅ | Fig.1/Fig.2 球体用 `mie_theory.py` 级数求和，秒级 |

### 1.2 FEM 原理（方法库只列了名字，这里展开）

FDTD 是「立方体格点 + 差分代导数」，FEM 完全不同，三步：

1. **弱形式（变分）**：把 $∇×∇×E − k_0^2 ε_r E = 0$ 乘检验函数 $v$ 积分、分部积分降阶 → 弱解方程。材料界面（$ε$ 跳变）自然处理。
2. **四面体网格 + 基函数（Galerkin）**：空间切成四面体（`FreeTet`），每个四面体上用线性 Lagrange 多项式插值 $E$。未知量 = 各网格节点场值。
3. **组装稀疏矩阵**：代入弱形式 → $A x = b$ 大型稀疏复线性方程组。0.3 网格 = 68,217,490 DOF（6800 万未知数）。

### 1.3 我们的关键技术（方法库之外）

**① 散射场公式（scattered-field formulation）**——`SolveFor=scatteredField` + 背景场 $E_b = E_0 e^{-ik_0 z}$（+z 平面波）。

平面波激励下 $E_{total} = E_{inc} + E_{scat}$，直接解总场会让平面波贯穿全域（每个节点都要精确表示振荡平面波，浪费且难）。散射场公式解析写入 $E_{inc}$，只数值解 $E_{scat}$（集中在纳米盘附近、向外衰减）：

$$∇×∇×E_{scat} − k_0^2 ε_r E_{scat} = k_0^2 (ε_r − 1) E_{inc}$$

右端是「源项」——入射场在散射体处激励。

**② 边界条件 SBC vs PML**——外边界要吸收外传散射场（否则反射污染解）。

- PML（完美匹配层）：边界外加人造吸收介质，理论零反射，**我们未用**（`pml=false`）。
- SBC（散射边界条件）：边界上一阶辐射条件 $n×∇×E_{scat} + ik E_{scat} ≈ 0$（近似 Sommerfeld 辐射条件），**我们用了**（`scattering_boundary=true`）。SBC 是近似，外域够大时够用（我们验证 3000→4000 nm 变化 <1%）。

**③ 多极矩后处理（不是 COMSOL 方法，是我们的公式）**——COMSOL 只解出场 $E$，ED/MD/EQ/MQ 用 Alaee 2018 Table 2 公式对场做体积积分：

- 电偶极 $p = ∫ P \, dV$（$P$ 为极化场）
- 磁偶极 $m = \frac{iω}{2}∫ r×P \, dV$
- 电四极、磁四极含高阶矩

精确多极矩（不依赖长波近似）对表面附近场梯度敏感 → **这正是 MD/EQ 网格收敛慢的根因**。

**④ 网格收敛 h-refinement + Richardson 外推**——mesh scale 1.0→0.7→0.5→0.3 是 h 细化（缩小四面体尺寸 h）。误差 $∝ C·h^p$：

| 通道 | 0.5→0.3 步进 | 收敛性 |
|---|---:|---|
| ED / MQ | 0.23% / 0.26% | ✅ 已收敛 |
| MD / EQ | 2.26% / 1.95% | ❌ 收敛慢（p≈1.3） |

MD/EQ 在 x=0.36 磁共振峰，表面场梯度极大 → 多极矩积分对表面四面体分辨率高度敏感，是**表面场奇异性主导的一阶收敛**（h 减半误差只减 ~40%）。Richardson 外推收敛值：MD ≈ 1.56e-12 m²（0.3 网格剩余 2.37%）。

**⑤ 直接 vs 迭代求解器**——COMSOL 频域默认**直接求解器**（MUMPS/PARDISO 稀疏 LU 分解），内存 $O(DOF^{1.5})$：

- 0.5 网格 14.7M DOF → 99 GB
- 0.3 网格 68.2M DOF → 需 ~900 GB（这就是为什么申请 900G）

迭代求解器（GMRES + 预条件器）内存 $O(DOF)$ 线性，但高频电磁问题收敛性差，未采用。

## 三、选型反思：有没有更好的方法？（用户 2026-08-13 追问）

### 3.1 核心洞察：球体根本不该用 FEM

**Fig.1（介电球）/ Fig.2（金球）是球体，有 Mie 解析解**——球谐函数级数求和，几十项收敛，Python 秒级完成。我们 `mie_theory.py`（a_n/b_n/c_n/d_n 系数）+ Table 2 体积积分都是纯解析/半解析计算，**双实现交叉 <0.01%**。

> 十几年前（2010s）没人用 1T RAM 的 FEM 算球体——因为**球体有解析解，直接算 Mie 级数**。Johnson & Christy 1972 材料数据 + Mie 公式，几十行 FORTRAN/Matlab 就出结果。

我们 Fig.1/Fig.2 之所以「方法自洽确凿」，正是因为我们用了正确的方法（Mie 解析解），而不是 FEM。

### 3.2 双金盘（Fig.3）才真正需要数值，但 FEM 直接求解非最优

双金盘（a=250nm 盘，t=80nm，g=120nm）**没有解析解**，必须数值。但方法有多种，资源差距巨大：

| 方法 | 内存 | 时间 | 十几年前是否主流 | 适用 |
|---|---|---:|---|---|
| **FDTD**（Lumerical 标准） | $O(DOF)$ 线性，几十 GB | 十几分钟～1h | ✅ **主流** | 宽带瞬态，金属纳米结构 |
| **BEM 边界元**（scuff-em） | 只离散表面，DOF 少 1–2 量级 | 分钟级 | ✅ 常用 | 金属（表面主导） |
| **DDA**（DDSCAT） | 偶极子阵列，比 FEM 省 | 分钟～小时 | ✅ 常用 | 任意形状纳米颗粒 |
| **T-matrix / MMS** | 球谐展开，半解析 | 秒～分钟 | ✅ 常用 | 规则形状（球/盘阵列） |
| **FEM + 直接求解器**（我们） | $O(DOF^{1.5})$，~900G | ~1h | ❌ 十几年前不现实 | 通用，但重 |

**关键结论**：十几年前金属纳米结构仿真的**标准是 FDTD（Lumerical Solutions）**，内存几十 GB 就够。FEM 频域 + 直接求解器是「重型」方法，3D 金属结构内存需求大，**只有在现在集群有 973G 才跑得动**。

### 3.3 我们为什么选了 FEM（诚实的工程理由）

1. **现成工具链**：COMSOL 6.3 Java API + 集群已有 comsol-runtime 镜像 + Parasolid 库已打通（B24-B25 的血汗），不用另装 Lumerical/DDSCAT。
2. **Fig.1(a) 论文标注 COMSOL**：Alaee 2018 自己用 COMSOL 做 Fig.1 验证，我们沿用同一软件便于方法对齐。
3. **集群够大**：magnus 更新后 973G 可申请，900G 跑得动。

**代价**：900G 内存 + 1 小时，且 MD/EQ 收敛慢（表面场奇异性）。

### 3.4 如果重来/继续深化的更优路径

1. **球体（Fig.1/2）**：继续用 Mie 解析解（已做），**永不碰 FEM**。
2. **双金盘（Fig.3）**：
   - 若只需散射截面谱：**FDTD**（Lumerical 或开源 Meep）内存线性，几十 GB，且一次仿真出全谱（FDTD 时域 → FFT 频域）。
   - 若要精确多极分解：**BEM**（scuff-em）表面离散，DOF 少，且天然适合金属。
   - 若坚持 COMSOL：**切迭代求解器 + 域分解**，内存 $O(DOF)$，可跑 0.2 网格。
3. **网格收敛慢的根源**：MD/EQ 对表面场敏感 → 与其 h 细化到 0.2（2TB 内存），不如**用更高阶基函数（p-refinement，二次/三次 Lagrange）**——高阶基函数对表面场收敛更快，同样的 DOF 达到更高精度，是 FEM 里比「无脑加密网格」更聪明的做法。

## 四、报告 methods 章节建议措辞

> 项目用 COMSOL Multiphysics 6.3 有限元方法（频域，`ElectromagneticWavesFrequencyDomain`）求解双金盘的散射场：采用散射场公式（背景场为 +z 传播平面波 $E_0 e^{-ik_0 z}$），外边界用散射边界条件（SBC），四面体网格（FreeTet），频域直接求解器。ED/MD/EQ/MQ 多极贡献由 Alaee 2018 Table 2 精确多极矩公式对解出的场做体积积分得到。网格收敛经 h-refinement（0.3–1.0）与 Richardson 外推评估：ED/MQ 收敛至 <0.3%，MD/EQ 因表面场奇异性收敛阶约 1.3，0.3 网格剩余误差约 2%（如实披露）。球体基准（Fig.1/2）由 Mie 解析解（球谐级数）独立计算，与 Table 2 积分交叉验证 <0.01%。
