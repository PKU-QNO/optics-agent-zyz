\subsection{金数据 3 源方案（用户拍板 2026-08-07）}

金介电函数\textbf{不用论文图读图提取}，改用 $\geq3$ 个独立公认数据源核对一致（十几年标准值测量偏差 $<$ 读图误差）：

\begin{itemize}
  \item \textbf{JC 1972} \cite{JohnsonChristy1972}（论文引用 [38]）：论文材料保真层，500--1935~nm，禁止外推
  \item \textbf{Olmon 2012} \cite{Olmon2012}（光谱椭偏，EV 样品）：方法验收层，500--2500~nm 全覆盖
  \item \textbf{McPeak 2015} \cite{McPeak2015}（等离激元金膜）：材料敏感性层，500--1700~nm
  \item Raki\'c 1998 \cite{Rakic1998}（COMSOL 内置 LD/BB）作第 4 参考
\end{itemize}

三源 550~nm 交叉核对（主 agent 亲算 + 子 agent 调研一致）见表 \ref{tab:gold550}。原始数据从 refractiveindex.info YAML 直接下载（CC0），存 \texttt{data/\_gold\_sources/} 含 manifest SHA256。
