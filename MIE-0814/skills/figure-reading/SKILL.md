# Figure Reading — 论文图读数与数字化

> 从 zotero mie-f 复现沉淀。**图读数是复现最大的隐性错误源**——一条 y 轴 log/linear 误判曾让整轮结论报废，被 vision-mcp 4 通道推翻后才纠正。

## 核心原则

**任何从图/位图读出的参数（坐标轴类型、刻度值、轴范围、峰位、曲线数据），模型读数一律视为「未核实线索」**，不是定稿。读到 ≠ 读对。

## 刻度/坐标轴铁律（4 条，必须全遵守）

1. **用权威最高分辨率原图**（figs/figN.png 或 PDF 提取的原图），不用低清 OCR 渲染、不用缩略图。
2. **vision-mcp 多通道收敛**：≥2 个裁剪图 + 整图独立读，**全一致才可信**。任何单通道（包括主 agent 亲看原图）都可能错——模型看同一张图两次可能给不同答案，必须多通道交叉。
3. **轴标题 vs 刻度分离**：竖排英文轴标题（如 `(C_sca/(λ²/2π))`）是**文字不是刻度**，读刻度前先剥离标题区域，否则竖排笔画混入刻度被误判为刻度线/数字。
4. **读到的值标 confidence + 提取方法 + 「未核实线索，待人工复核」**，不视为定稿。

## log / linear 判定（最易错的单点）

- **别凭直觉判 log/linear**：一次 y 轴被误判为 log，实际是 linear 1,3,5,7，被 vision-mcp 4 通道推翻。
- 判定信号：看**刻度间距是否等距**（linear 等距，log 每十倍等距）、**轴标签是否含 10 的幂**、**网格线分布**。
- 多通道读同一根轴，全一致才算定论；不一致就标「未核实，待人工复核」，**不硬选一个继续算**。

## 数字化取点（digitization）

- 从曲线提取数据点：用高分辨率原图，按坐标轴标定（先读刻度确定物理量↔像素的映射），再沿曲线取点。
- 曲线数据点只用于**峰位/形态定性比对**，不用于精确数值标定——读图数据永远是 `surrogate_fallback`，不是物理复现。
- 若论文是纯理论（曲线 = 标准解析解，如标准 Mie），**优先自己算解析解**，别读图——读图数据放弃，人工目视相似即可。

## 人工复核流程（两条硬停点）

1. **下一步开工前**：formalization/参数定稿前，用户亲自核对该步从图提取的参数。
2. **整个 workflow 结束前**：把所有「从图提取的参数」列清单，用户逐项复核一遍再定稿 REPORT。

## 读图结果标注格式

每个读出的值都带四要素：
- `value`：读数
- `method`：提取方法（vision-mcp 裁剪图 / 整图 / 像素统计）
- `confidence`：低 / 中 / 高
- `review_status`：未核实线索（默认）→ 已人工复核（用户确认后）

## 与 paper-reproduction 的关系

本 skill 是「读图」的单一权威来源。paper-reproduction / sub-agent 里的「刻度/坐标轴铁律」应引用本 skill，不重复正文。读图只是复现的一步，编排逻辑在 paper-reproduction。
