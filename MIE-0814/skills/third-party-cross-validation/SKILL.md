# Third-Party Cross-Validation — 第三方交叉验证

> 从 zotero mie-f B34（第三方交叉）+ RES-ALAEE/RES-GRAHN（文献调研）沉淀。
> 核心目的：**不靠「看起来像」验证，靠独立实现/独立数据源的交叉印证。**

## 三类交叉验证（按证据强度排序）

### ① 同对象双实现（最强：方法自洽）

同一物理对象，用**两条独立数学路径/实现**算，交叉比对：
- 例：Table 2 精确多极矩体积积分 vs 独立 Mie 系数（同对象双实现，ED 0.427%/MD 0.887%/MQ 0.718%）。
- 例：自己实现的 Mie vs miepython（独立库）。
- 判据：双实现交叉 <1% = 强自洽（偶极/磁四极），1-2% 可接受但注明网格/实现限制。

### ② 第三方软件管线（不同方法，需诚实区分对象）

用别的软件/方法（FDTD/BEM/DDA/T-matrix）算**同一结构**，交叉：
- Tidy3D / Lumerical（FDTD）、pyGDM2 / DDSCAT（DDA）、MENP / scuff-em（BEM）、miepython（Mie）。
- **关键诚实区分**：第三方数据若算的是**不同物理对象**（如 c-Si 球 vs 你的金球），则只能「方法学印证」，**不宣称曲线重合**——别调阈值把差异抹平。

### ③ 作者原始数据（若有则对齐，没有就放弃读图）

- 调研论文有没有公布原始数据：DOI 数据仓库（Zenodo/Figshare）、作者主页、补充材料、GitHub。
- 纯理论论文（曲线 = 标准解析解，如 Alaee 2018 的曲线就是标准 Mie）→ **没有作者数据可对齐**，直接自己算解析解，读图数据放弃，人工目视相似即可。
- 有电子数据 → 用电子数据对齐，**读图数据可以退役**。

## 调研方法（怎么找第三方）

1. 先查作者是否公布原始数据（论文正文「data availability」+ DOI 数据仓库 + 作者机构主页）。
2. 再查有没有人复现并提供电子资料（arXiv 复现 repo、GitHub、博客、课程作业）。
3. 纯解析可解的对象，直接找成熟库（miepython / scipy.special / menp / pyGDM2），不读图。

## 诚实口径（B34 核心教训）

- **同对象双实现**（同一物理对象两条路径）→ 可以下「方法自洽」结论。
- **不同对象**（第三方算的是别的结构/材料）→ 只能下「方法学印证」，明确标注「不宣称物理曲线重合」。
- **读图数据**永远是 `surrogate_fallback`，第三方电子数据/双实现才是物理验证。
- 差异不达标**不调阈值抹平**——如实披露差异 + 归因（网格精度 / 对象不同 / 管线不同）。

## 与 numeric-verification 的关系

本 skill 是 numeric-verification「多近似方法对比」那一判据的**外部扩展**——numeric-verification 讲三条判据框架，本 skill 讲「怎么找 + 怎么诚实用第三方」。两者配套：先按 numeric-verification 定验证矩阵，再用本 skill 找第三方数据填「多方法对比」那一格。
