# 解析基准校验 → 数值信任（Fig.3 类非解析结构的验证迁移）

> 核心：解析工作不是「做完就扔」，它是数值工作的**验金石**。Mie 解析解 = 数值求解器的基准。

## 核心模式：validate-then-trust

数值求解器**首次用于新结构（非解析）前**，必须先：

1. 用**同一个求解器**复现一个**有解析解的结构**（球体 = Mie 解析解）。
2. 跟解析解对到 <1%（偶极/磁四极；四极可放宽 ~2% 取决于网格）。
3. 才信任它算非球体结构。

**为什么**：非球体没有解析真值，无法直接「跟答案比对」。解析球体证明求解器本身的设置（散射场公式 / 材料插值 / 网格 / 多极矩后处理）全对，剩下的误差才是结构本身。

## 球体校验能定位什么错误

用同一管线算球体对比 Mie，能逐项定位：散射场公式错？材料色散插值错？多极矩体积分系数错？网格不够？——球体都对不上，非球体结果不可信；球体对上 <1%，非球体误差才可归因于结构。

## 球体校验清单

| 项 | 值 |
|----|----|
| 结构 | 单球（介电 ε_r=6.25 或金 Johnson-Christy） |
| 尺寸参数 x = 2a/λ | 覆盖 0.2–1.0（含磁共振区 kr~1） |
| 比对象 | Mie 解析解（miepython 或自实现 a_n/b_n/c_n/d_n） |
| 多极矩 | ED/MD/EQ/MQ 四通道 |
| 判据 | 双实现交叉 <1%（四极 ~2%） |

## 长波近似适用边界（该不该上数值的物理判断）

- `kr ≪ 1`（小尺寸参数、远离共振）→ **偶极近似/长波近似够用**（Alaee Table 1），甚至 coupled dipole（CDA）。
- `kr ~ 1`（共振区，尤其磁共振峰）→ 长波近似**失效**（介电球 s=0.75 处长波 ED 136% / MD 277% 误差），必须精确多极矩（Table 2）或全数值。
- 判断顺序：先估尺寸参数 x = 2a/λ → x ≪ 1 且不靠近共振先试解析/近似；x ~ 1 或磁共振直接上数值。

## 迁移到 Fig.3 类（非解析）的完整链路

```
读图提取结构+参数（figure-reading）
  → 方法选型（comsol-scattering）
  → 建 COMSOL 模型（comsol-scattering）
  → ★球体校验：同求解器复现 Mie <1%（本 reference）★
  → 非球体结构求解
  → 多极矩后处理（comsol-scattering）
  → 网格收敛 + Richardson（comsol-scattering / numeric-verification）
  → 物理验证三元组（numeric-verification）
  → 第三方交叉（third-party-cross-validation）
```

## 诚实口径

- 球体校验通过 = 求解器可信，**不等于**非球体结果对（还有网格收敛 / 结构本身物理）。
- 球体校验不过 → 非球体结果**不可信**，先修球体（最可能：散射场公式 / 材料 / 多极矩积分系数）。
- 非球体没有解析真值时，用「两种数值方法互验」（FEM vs BEM）+ 网格收敛 + 三元组，如实披露残差。
